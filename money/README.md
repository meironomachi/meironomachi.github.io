# $TDL

수입과 지출, 예산을 한눈에 보는 가계부. `meiro.kr/money/` 에서 열립니다.
일기장(STDL)과 같은 Supabase 프로젝트와 로그인을 씁니다.

- 이번 달: 수입 / 지출 / 남은 돈 (이체·저축·결제 취소는 빼고 계산), 지난달 대비
- 예산: 한 달 전체와 분류별 예산, 80%가 넘으면 주황·넘으면 빨강, 남은 날 하루에 쓸 수 있는 돈
- 내역: 여러 개 지우기 (필터 후 "보이는 내역 모두 선택" → 삭제, 이체 짝은 반대쪽도 함께)
- 빠른 입력(+ 버튼): 지출·수입·이체·저축, 자주 쓰는 곳 버튼, '다음부터 이 곳은 이 분류' 규칙
- 가져오기: 은행 거래내역 엑셀(xlsx)·CSV·PDF. PDF는 pdf.js로 글자 위치를 읽어 제목 줄 칸에 맞춰 표로 되돌림(두 줄로 쓴 일시·내용은 이어 붙임). 비밀번호 PDF는 물어봄. 표가 아닌 PDF는 붙여넣기처럼 읽음. 카카오뱅크 형식(거래일시 | 구분 | 거래금액 | 거래 후 잔액 | 거래구분 | 내용)을 읽고,
  출금액·입금액이 따로 있는 파일도 읽음. 파일은 브라우저 안에서만 읽음
  - 같은 내역은 건너뜀, 직접 넣어 둔 내역과 같은 결제는 하나로 합침
  - 결제 뒤 같은 금액이 '체크카드(기타)·취소'로 들어오면 취소 짝
  - 다른 내 계좌로 10분 안에 같은 금액이 오가면 이체 짝
  - 적금·예금·세이프박스는 저축
- 캡처 글자 붙여넣기 (무료): 아이폰 사진 앱 텍스트 인식으로 복사한 거래내역 글자를 붙여 넣으면 읽음. 하나원큐·NH 화면 모양.
  날짜 줄이 잘려 날짜를 모르는 줄은 확인 표에서 채움. 브라우저 안에서만 처리
- 캡처 가져오기 (API 키 있을 때): 은행 앱 거래내역 목록 캡처를 올리면 Edge Function `money-ocr`가 Claude로 읽어 날짜·시각·누구·금액·잔액을 돌려줌.
  긴 캡처는 브라우저에서 조각내 보냄. 읽은 줄은 확인 표에서 고치거나 뺀 뒤, 파일 가져오기와 같은 중복·취소·이체 확인을 거쳐 저장. 이미지는 저장하지 않음
- 계좌: 파일의 '거래 후 잔액'으로 잔액을 맞춤, 현금은 시작 잔액 + 직접 입력
- 계좌번호, 카드번호, 은행 비밀번호는 저장하지 않음

## 처음 설정

Supabase **SQL Editor**에서 `supabase/money.sql` 실행 (일기장 `schema.sql`을 먼저 실행한 프로젝트에서)

캡처 가져오기를 쓰려면 Supabase **Edge Functions → Secrets**에 `ANTHROPIC_API_KEY`를 넣고,
`supabase/functions/money-ocr/index.ts`를 `money-ocr` 이름으로 배포 (JWT 확인 켜 둠)
