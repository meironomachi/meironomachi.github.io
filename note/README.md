# MEIRONOTE ✍🏻

일기장 모양 그대로 글을 백업해 두는 곳. `meiro.kr/note/` 에서 열립니다.
일기장(STDL)과 같은 Supabase 프로젝트와 로그인을 쓰고, 기분 태그와 사진 저장소도 일기장과 같이 씁니다.

- 글: 날짜, 제목, 날씨, 기분, 사진, 서식 있는 본문(굵게·기울임·취소선·형광펜·글씨 색), 댓글 (일기장의 타임테이블은 없음)
- 폴더: 만들기·이름·색·순서 바꾸기, 지우면 안의 글은 '폴더 없음'으로
- 자동 저장: 입력이 멈추고 4초 뒤 서버에 저장 (이 기기에도 0.6초마다 따로 저장)
- 임시저장: 누를 때마다 버전이 하나씩 남음. 올리기 전 글은 목록에 '임시저장'으로 보임
- 버전 기록: 자동 저장·임시저장·올림 버전을 보고 골라서 불러오기
- 월간 리포트: 그달에 올린 글 수, 글자 수(공백 포함/제외), 단어 수, 날짜별·폴더별, 글마다 수
- 검색: 제목·내용, 기간, 폴더, 기분, 임시저장 글 포함 여부

## 처음 설정

Supabase **SQL Editor**에서 `supabase/note.sql` 실행 (일기장 `schema.sql`, `accounts.sql`을 먼저 실행한 프로젝트에서)
