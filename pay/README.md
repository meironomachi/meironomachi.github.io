# MEIROPAY 💰

근무 시간을 적으면 받을 월급을 계산해 주는 곳. `meiro.kr/pay/` 에서 열립니다. 일기장과 같은 로그인을 씁니다.

- 큰 달력에서 날짜를 눌러 근무 적기: 일하는 곳, 시작·끝 시각(자정 넘김 가능), 휴게시간, 그날만 다른 시급, 메모
- 일하는 곳마다 시급, 색, 세금 방식(3.3% · 4대보험+근로소득세 · 세금 없음), 주휴수당, 5인 이상 가산수당(연장·야간 0.5배)
- 이번 달 세전·떼는 돈·세후, 일하는 곳별 명세, 전월 대비(세전·세후 %, 공제율 %p, 근무 시간 %)
- 4대보험은 2026년 근로자 부담 요율(`js/pay.js`의 RATES), 근로소득세는 간이세액표 공식(본인 1명) 근사치
