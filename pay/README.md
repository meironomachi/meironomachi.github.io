# MEIROPAY 💰

근무 시간을 적으면 받을 월급을 계산해 주는 곳. `meiro.kr/pay/` 에서 열립니다. 일기장과 같은 로그인을 씁니다.

- 큰 달력에서 날짜를 눌러 근무 적기: 일하는 곳, 시작·끝 시각(자정 넘김 가능), 휴게시간, 그날만 다른 시급, 메모
- 일하는 곳마다 시급, 색, 세금 방식(3.3% · 4대보험+근로소득세 · 세금 없음), 주휴수당, 연장수당·야간수당(각각 0.5배, 따로 켜고 끔)
- 반복 근무 추가: 요일별 시간(예: 매주 일 12~20시, 수 17~22:30)으로 기간 안의 근무를 한 번에 넣기, 이미 있는 근무는 건너뜀, 일하는 곳마다 패턴 기억
- 일당으로 받는 곳(일용직): 금액만 적으면 되고 시각은 선택, 세금은 3.3% · 일용직 세금(하루 15만 원 넘는 부분 2.7% + 고용보험 0.9%) · 세금 없음
- 근무 기록이 없는 달은 급여를 직접 적기(세전, 세후는 선택). 적어 두면 그 곳의 그달 계산 대신 씀
- 이번 달 세전·떼는 돈·세후, 일하는 곳별 명세, 전월 대비(세전·세후 %, 공제율 %p, 근무 시간 %)
- 4대보험은 2026년 근로자 부담 요율(`js/pay.js`의 RATES), 근로소득세는 간이세액표 공식(본인 1명) 근사치
